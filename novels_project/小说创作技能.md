# 小说创作技能

## 简介
网文小说创作辅助工具，整合 webnovel-writer + 第三版规则提示词

## 适用场景
- 创建新小说项目
- 规划大纲（400章粗纲 → 20章细纲）
- 创作正文（每章2500字+）
- 添加吐槽元素

## 使用流程

### Step 1: 创建项目结构
```
mkdir -p 小说名/大纲
mkdir -p 小说名/正文
mkdir -p 小说名/.webnovel
```

### Step 2: 400章粗纲
按每20章1个小故事规划，共15个故事：
- 包含：境界体系、地图切换、爽点分布
- 格式：章号-标题-核心爽点-钩子

### Step 3: 20章细纲
每章包含：
- 剧情概述
- 钩子类型（危机/悬念/情绪/选择/渴望）
- 爽点模式（装逼打脸/扮猪吃虎/越级反杀等）
- 吐槽点（每2章1点）

### Step 4: 正文创作
- 遵循细纲
- 每章2500字+
- 使用轻松幽默风（x.2）或技术流修仙文（x.7）

---

## 核心原则

### 防幻觉三定律
1. 大纲即法律
2. 设定即物理
3. 发明需识别

### 追读力设计
- 钩子：每章必须有
- 爽点：每5章至少1个
- 吐槽：每2章1点
