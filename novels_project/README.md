## 创作规范
1. **大纲即法律** - 遵循大纲
2. **设定即物理** - 不自相矛盾
3. **新实体入库** - 记录所有新角色/势力

## 创作流程
```
Step 1: 读取上章摘要和大纲
Step 2: 生成创作任务书
Step 3: 创作章节（2500字）
Step 4: 六维审查
Step 5: 更新章节摘要
Step 6: 提取实体入库
```
