## 二、创作流程（每次必遵守）

### 【写作前】

#### 重要提醒：每次写作前必须先提供四段结构！
```
1. 开头（约500字）
2. 中段（约800字）
3. 高潮（约600字）
4. 结尾（约300字）

必须包含：
- 本章爽点
- 伏笔埋设

等待用户确认后再开始写作！
```

#### Step 1: 读取设定（必须！）
```
1. 打开 workflow.md（本文件）→ 确认当前进度
2. 读取 地图/小地图/xxx.md → 确认本章场景
3. 读取 人物卡/主角模板.md → 确认主角状态
4. 读取 金手指/金手指设定.md → 确认能力限制
5. 读取 大纲/大纲.md → 确认本章剧情
```

#### Step 2: 规划章节
- [ ] 本章剧情是什么？
- [ ] 需要哪些人物出场？
- [ ] 场景在哪里？
- [ ] 爽点/矛盾是什么？
- [ ] 金手指是否使用？如何限制？

### 【写作中】
- 每章2200字左右（汉字，不含标点）
- 保持节奏紧凑
- 埋设伏笔
- 爽点安排
- **去AI味技巧**：
  - 口语化表达，少用"之乎者也"
  - 减少套话（"只见"、"但见"少用）
  - 增加情绪波动，主角有心理活动
  - 对话真实自然，避免完美辞藻

### 【写作后】（必须！）

#### Step 3: 填写章节摘要
1. 创建/更新 `章节摘要/chapter_xxx.md`
2. 记录：本章剧情、人物出场、战斗、金手指使用

#### Step 4: 更新设定
- [ ] 主角境界有变化？→ 更新人物卡
- [ ] 有新场景？→ 创建小地图
- [ ] 有新人物？→ 更新人物卡
- [ ] 有新势力？→ 更新世界观
- [ ] 有新物品产出？→ 记录到小地图

#### Step 5: 更新进度
- 更新 workflow.md 当前进度

## 五、注意事项

1. **金手指限制**：严格遵守当前阶段的限制，开局不能无敌
2. **敌人强度**：匹配主角实力，不能太弱或太强
3. **地图细节**：每个重要场景都要有独立小地图
4. **人物成长**：记录每次境界变化
5. **伏笔回收**：记得回收之前埋的伏笔
6. **章节摘要**：每章写完必须填写！
